          HƯỚNG DẪN CÀI ĐẶT & SỬ DỤNG - CAPCUT AUDIO TO TEXT BATCH STUDIO

Công cụ tự động chuyển đổi âm thanh / giọng nói thành văn bản phụ đề (Auto Subtitle)
hàng loạt (Batch Queue) và chèn trực tiếp vào dự án CapCut PC hoặc xuất file .SRT / .TXT 
bằng AI Whisper Large-v3 trên GPU Google Colab Tesla T4 16GB.

--------------------------------------------------------------------------------
HƯỚNG DẪN SỬ DỤNG VỚI GOOGLE COLAB GPU (CHỈ CẦN 3 BƯỚC):
--------------------------------------------------------------------------------
Bước 1: Lấy mã nguồn Colab 1-Click
   - Mở phần mềm CapCut STT Tool trên máy tính của bạn (chạy file "run.bat").
   - Nhấp vào nút "📋 Copy Code Colab" ở góc trên bên phải. Nút sẽ chuyển sang "✅ Đã Copy!".

Bước 2: Chạy Server trên Google Colab
   - Nhấp vào nút "⚡ Mở Colab" trên Tool (trình duyệt web sẽ tự động mở Google Colab).
   - Trên Google Colab:
     1. Vào menu: Runtime -> Change runtime type -> Chọn phần cứng "T4 GPU" -> Bấm Save.
     2. Tạo 1 ô code trống, dán (Ctrl+V) mã nguồn vừa copy vào.
     3. Bấm nút Play (Run) để chạy ô code đó.
     4. Chờ 1-2 phút, màn hình Colab sẽ hiện ra đường link:
        =================================================================
        🚀 KẾT NỐI GPU COLAB THÀNH CÔNG (TESLA T4 16GB - WHISPER LARGE-V3)!
        👉 DÁN LINK NÀY VÀO TOOL DESKTOP: https://xxxx-xxxx.trycloudflare.com
        =================================================================

Bước 3: Kết nối và Chạy hàng loạt trên Tool
   - Dán đường link "https://xxxx-xxxx.trycloudflare.com" vào ô "Link Colab" trên Tool.
   - Bấm nút "🔗 Kết nối" -> Xuất hiện chấm xanh "● ĐÃ KẾT NỐI: Tesla T4 (Trống 13.5GB VRAM)".
   - Sử dụng Hàng Đợi (Batch Queue):
     + Bấm "➕ Thêm Tệp" hoặc "📂 Thư Mục": Chọn hàng loạt tệp âm thanh/video ngoài máy (.mp3, .wav, .mp4, .m4a,...).
     + Bấm "➕ Đưa Dự Án Vào Hàng Đợi": Chọn một hoặc nhiều dự án CapCut bên cột phải để đưa vào hàng đợi.
   - Tùy chọn cấu hình:
     + Chọn ngôn ngữ (Mặc định Tiếng Việt), số từ tối đa mỗi đoạn (mặc định 13 từ).
     + Kiểu phụ đề: Chọn "Nhóm Sub (Áp dụng cho tất cả)" hoặc "Văn bản độc lập".
     + Tích chọn "Tự động xuất file .SRT và .TXT" nếu muốn lưu phụ đề rời cho file media.
   - Bấm nút "⚡ BẮT ĐẦU CHẠY HÀNG CHỜ (BATCH PROCESS)":
     + Hệ thống sẽ tự động nén âm thanh gửi lên GPU Colab Tesla T4 xử lý lần lượt từng mục.
     + Phụ đề sẽ tự động chèn vào CapCut hoặc xuất ra file .SRT ngay lập tức!

--------------------------------------------------------------------------------
LƯU Ý RẤT QUAN TRỌNG KHI XỬ LÝ DỰ ÁN CAPCUT:
--------------------------------------------------------------------------------
- Trước khi chạy hàng đợi có chứa Dự Án CapCut, hãy QUAY RA TRANG CHỦ (Homepage) 
  của CapCut hoặc ĐÓNG HẲN CapCut lại.
- Tránh mở màn hình chỉnh sửa dự án đó trong CapCut, vì CapCut sẽ tự động ghi đè 
  và làm mất phụ đề mới được tạo ra.
- File dự án CapCut luôn được tự động sao lưu dự phòng thành "draft_content.json.bak".
